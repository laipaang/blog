THE BIG PICTURE

Agent 的表现，
由整条链路共同决定。

这份原作是一部面向实践者的系统综述与参考书，并非只提出一个新算法的实验论文。它把 LLM 架构、GPU 系统、后训练、推理能力，以及 RAG、记忆、工具和编排放在同一张图上。

课程采用相同的全栈视角，但不逐页翻译。我们把原书 31 章重组为 7 章 28 节：先建立计算与学习的共同语言，再讨论系统如何使用模型，最后用任务级证据评估结果。

这门课要建立的判断力遇到一个 Agent 问题时，先判断它来自模型能力、上下文信息、工具执行、控制流程，还是评估方法，再决定该改哪里。
WHAT YOU WILL BUILD
  • 01画出文本生成的计算过程，并分清模型参数、上下文和 KV Cache。
  • 02比较 SFT、偏好优化和推理 RL 的目标与系统成本。
  • 03组合检索、记忆、工具和执行循环，设置明确的完成条件。
  • 04用任务成功率、成本、延迟和失败轨迹评价一个系统。

适合具备基础机器学习、概率与 Python 阅读能力的工程师。熟悉训练系统的读者可在后续按需跳读；第一节仍建议用于统一术语。

A RUNNING EXAMPLE

一条贯穿课程的工程线索。

「这个训练任务变慢了，帮我找到可验证的原因。」

我们将以训练任务诊断助手作为自编的教学案例：读取日志与性能证据，提出候选原因，调用分析工具，再生成可以复核的诊断报告。这是本课自编案例；原书使用 Guardian Angel 医疗示例。本案例使用合成输入，用于逐章搭建可复核的分析过程。

第一章只解释底层模型如何生成 token。后续才逐步加入检索、工具、任务状态与评估。每个阶段都追问：新增模块解决了哪个问题？有什么证据证明它有效？

HOW TO LEARN

每一节，都留下可检查的理解。

先读直觉，再看机制。讲义将概念、公式与工程含义连接起来。互动图解释因果与状态变化；凡是教学合成数据都会标明，不与真实模型测量混用。

阅读与演示共用一份内容。第一节提供演示模式，可用左右方向键换页、Esc 退出。普通阅读模式保留完整长文，支持手机浏览与打印。

重视边界，不把参考书当最终规范。原书中的经验、框架 API 和具体性能数字需要放回版本、硬件和任务条件理解。本课会明确指出必要的限定，例如自回归模型的因果遮罩。

当前开放内容。课程整体介绍与 1.1 的完整讲义、交互和测验。其余 27 节展示学习目标与目录，后续逐步扩展。
