## 1. 模型的工作原理

先弄清模型在算什么，再讨论它能做什么。 原书 Ch.1–2

- 1.1 LLM 如何工作：从文本到下一个 Token — 建立生成过程、概率分布与运行时的共同语言。 [已发布]
- 1.2 Tokenization 与 Transformer 的内部结构 — 从离散符号、位置到注意力与上下文表示。 [规划中]
- 1.3 预训练、SFT、LoRA 与 MoE — 分清训练目标、适配方式和模型架构。 [规划中]
- 1.4 解码、压缩与推理加速 — 理解策略、精度与速度的不同作用。 [规划中]

## 2. 训练与推理系统

把模型抽象映射到真实硬件和运行时。 原书 Ch.2、11

- 2.1 GPU、存储层次与 Roofline — 用计算、带宽与访存解释性能。 [规划中]
- 2.2 显存账本与分布式并行 — 参数、梯度、优化器状态与通信的取舍。 [规划中]
- 2.3 KV Cache、分页与持续批处理 — 理解推理服务如何复用状态和组织请求。 [规划中]
- 2.4 性能分析、预算与故障恢复 — 连接吞吐、延迟、资源利用和稳定性。 [规划中]

## 3. 对齐与推理学习

从学习信号理解模型行为如何改变。 原书 Ch.3–13

- 3.1 MDP、策略梯度与 Actor-Critic — 把语言生成放进序列决策框架。 [规划中]
- 3.2 奖励模型、RLHF 与 PPO — 拆解偏好数据、奖励与策略更新。 [规划中]
- 3.3 DPO、GRPO 与算法选择 — 比较不同学习目标和系统成本。 [规划中]
- 3.4 推理 RL 与 Test-time Scaling — 区分训练推理能力与分配推理计算。 [规划中]

## 4. 从模型到 Agent

从单次输出走向有状态、可停止的执行闭环。 原书 Ch.12、15、18–21

- 4.1 模型、工作流与 Agent 的边界 — 按控制权和反馈方式识别系统形态。 [规划中]
- 4.2 ReAct、规划与反思 — 比较不同动作组织方式及失败模式。 [规划中]
- 4.3 Harness、上下文与循环工程 — 让模型获得状态、工具和可检查的反馈。 [规划中]
- 4.4 图编排、检查点与停止条件 — 用明确的状态和边界管理长任务。 [规划中]

## 5. 外部知识与长期记忆

让信息能够被检索、更新和追溯。 原书 Ch.16–19

- 5.1 RAG：检索、分块与索引 — 区分参数知识、外部证据与上下文。 [规划中]
- 5.2 混合检索、重排与 Agentic RAG — 让检索决策服务真实任务。 [规划中]
- 5.3 工作记忆、情景记忆与语义记忆 — 设计不同生命周期的信息存储。 [规划中]
- 5.4 记忆更新、时效与上下文预算 — 管理冲突、过期事实与有限窗口。 [规划中]

## 6. 工具协议与多 Agent 协作

把模型的动作意图接到可管理的执行系统。 原书 Ch.23–27

- 6.1 工具调用：Schema、执行与结果校验 — 分清生成调用和实际执行的责任。 [规划中]

- 7.1 模型评估与任务评估 — 把 token 指标、答案质量与任务成功分开。 [规划中]
